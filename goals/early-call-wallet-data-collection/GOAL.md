# Early-call wallet data collection

Goal ID: goal_6045e60b8858
Goal slug: early-call-wallet-data-collection

## Description
Collects on-chain wallets that bought BSC memecoins early and still hold them, to identify consistent early callers for paper screening, promoting a wallet only after at least three tokens plus 30-day profit-and-loss verification, with cluster mapping for funding and related wallets. A 2-hour holder-candidate monitor tracks the batch 3 candidates as internal analysis for money-direction signals, staying silent except for a full promotion. Interim hold checks continue while full wallet-activity mode waits on GMGN login, after Google and Telegram login routes failed from the browser VM and the user completed a password reset with a secure credential card still pending.
