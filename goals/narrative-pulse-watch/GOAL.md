# Narrative pulse watch

Goal ID: goal_bb80d41258f6
Goal slug: narrative-pulse-watch

## Description
Watches BSC narrative sources for early signals that a memecoin topic is about to become widely discussed, using rising mentions from a low base, multi-source convergence, and related leading indicators. It reports only genuinely new early signals and stays silent otherwise; a signal is discovery only and never a buy recommendation, with any trade still requiring full gates and user approval.
